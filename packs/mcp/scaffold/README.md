# @@NPM_PACKAGE@@-mcp

An [MCP](https://modelcontextprotocol.io) server for the @@CLIENT_NAME@@ API, in code mode: a
`search` tool over its TypeScript SDK, and an `execute` tool running scripts against it in a
sandbox with no network, files or environment, its calls made by the server with your API key.

## Hosted

```sh
docker run -p 8080:8080 ghcr.io/@@PACK_REPO@@
```

MCP clients connect to `http://<host>:8080/mcp` with their API key: `Authorization: Bearer <key>`
or `X-API-Key`. `--read-only` serves only reads; `--help` lists the limits.

For one-click connectors (claude.ai, ChatGPT), the server is its own OAuth server: users paste
their API key once on its consent page, kept encrypted in a SQLite file.

```sh
docker run -p 8080:8080 -v mcp-data:/data -e MCP_OAUTH_SECRET="$(openssl rand -base64 32)" \
  ghcr.io/@@PACK_REPO@@ --oauth --store /data/grants.db --public-url https://mcp.example.com
```

Keep the secret: changing it revokes every grant.

### Self-hosted, keys and scripts apart

`compose.yaml` runs the server in two containers: `mcp` keeps the grants and makes every API
call; `sandbox` runs the scripts (`perseid-mcp runner`), holds no key, and sits on a network
with no route out but to `mcp`. Uncomment `runtime: runsc` where the host has
[gVisor](https://gvisor.dev).

```sh
MCP_OAUTH_SECRET="$(openssl rand -base64 32)" MCP_RUNNER_TOKEN="$(openssl rand -base64 32)" \
  MCP_PUBLIC_URL=https://mcp.example.com docker compose up -d
```

### Cloudflare Workers

```sh
npx wrangler d1 create @@HEADER_PREFIX@@-mcp-oauth   # unless the deploy creates it
npx wrangler secret put MCP_OAUTH_SECRET            # 32 characters or more
npm run deploy
```

`wrangler.jsonc` holds the settings: `MCP_AUTH` (`oauth`, `api-key` or `authorization-server`)
and `MCP_SANDBOX`. `quickjs` runs scripts in QuickJS inside the Worker, on any plan, with no
charge per script; a loop is stopped after about 6 seconds of work (`MCP_CPU_BUDGET`), within
the Worker's CPU limit. `dynamic-workers` runs each script in a Dynamic Worker of its own, full
V8 with no network, on Workers Paid, billed per script, its CPU bounded by Cloudflare.

## Local

In Claude Desktop, open [the bundle](https://github.com/@@PACK_REPO@@/releases/latest/download/@@NPM_PACKAGE@@-mcp.mcpb):
it asks for the API key, and runs scripts in QuickJS, with nothing else to install. With Claude
Code:

```sh
claude mcp add @@NPM_PACKAGE@@ -e @@ENV_PREFIX@@_API_KEY=... -- npx -y @@NPM_PACKAGE@@-mcp
```

In another client's configuration (Cursor, VS Code):

```json
{"mcpServers": {"@@NPM_PACKAGE@@": {"command": "npx", "args": ["-y", "@@NPM_PACKAGE@@-mcp"], "env": {"@@ENV_PREFIX@@_API_KEY": "..."}}}}
```

Clients with a shell may rather use the CLI's own `mcp`, a tool per operation.

## Layout

`src/generated/` and `package.json` are regenerated by perseid from the API's spec, through pull
requests: don't edit them. The runtime is the `perseid-mcp` package. `src/main.ts`, the `Dockerfile`
and `.github/` are yours.
